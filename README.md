# Sistema de Gestión y Reservas - Fase 4

Proyecto desarrollado en **Python** orientado a objetos para la gestión de clientes, asesorías, servicios, equipos y reservas de salas.

# Estructura del Proyecto

* `main.py`: Archivo principal de ejecución de la aplicación.
* `cliente.py`: Gestión y modelo de datos de los clientes.
* `entidad.py`: Definición de las entidades base del sistema.
* `asesoria.py`: Lógica relacionada con la programación y manejo de asesorías.
* `servicio.py`: Administración de los servicios disponibles.
* `sala.py`: Gestión de disponibilidad y características de las salas.
* `equipo.py`: Control y asignación de equipos requeridos.
* `reserva.py`: Lógica principal para la creación y control de reservas.
* `excepciones.py`: Manejo personalizado de errores y excepciones del sistema.
* `logger.py`: Registro de eventos y actividad de la aplicación.

# Requisitos e Instalación

1. Tener instalado *Python 3.10* o superior.
2. Clonar este repositorio en su equipo local:

   git clone https://github.com/joanfercho/fase4-software-fj.git

 3. Ingresar a la carpeta del proyecto y ejecutar el archivo principal:

    python main.py
